# CLAUDE.md — OoverrFinancee

Семейный финансовый трекер (монорепозиторий TypeScript: веб-дашборд + Telegram-бот + общий пакет + Supabase).

Этот файл собран из трёх документов проекта, которые подключаются целиком (директива `@` — содержимое файлов подгружается в контекст автоматически):

@PROJECT_RULES.md

@ARCHITECTURE.md

@DATABASE.md

## Дополнительно (то, чего нет в документах выше)

- Порядок работы — [ROADMAP.md](./ROADMAP.md), баги — [BUGS.md](./BUGS.md) и `bugs*.md` (формат: Описание / Ожидаемое / Фактическое / Где чинить / Приоритет).
- Команды из корня: `npm install`, `npm run dev:web`, `npm run dev:bot`, `npm run build:web`, `npm run typecheck` (запускай после правок).
- При расхождении документов доверяй `ARCHITECTURE.md` и предупреди пользователя.
- В `PROJECT_RULES.md` написано «я не программист, вставляю код вручную, ты не видишь проект» — для Claude Code это неактуально: файлы доступны напрямую, правь их сам, но только те, что относятся к задаче, и соблюдай остальные правила оттуда (план → правки → «как проверить», вопрос про отметку в ROADMAP).
